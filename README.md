# کار روز (KarRooz) — نسخه ۳ (Persian Calendar & Date-Based Planning)

برنامه تحت‌وب مینیمال، متمرکز و شخصی برای مدیریت تسک‌ها، یادداشت‌ها، تقویم خورشیدی و پروژه‌ها به زبان فارسی با ساختار داده محلی.

---

## راهنمای اجرا (How to Run)

پروژه با استفاده از React 19، Vite، TypeScript و کتابخانه استاندارد محاسبات تقویمی `jalaali-js` پیاده‌سازی شده است.

### پیش‌نیازها
- Node.js نسخه 18 یا بالاتر
- npm

### دستورات اجرایی
```bash
# نصب وابستگی‌ها
npm install

# اجرای سرور توسعه محلی
npm run dev

# بررسی عدم وجود خطای تایپ و لایه لود
npm run lint

# ساخت نسخه پروداکشن
npm run build
```

برنامه روی پورت ۳۰۰۰ در دسترس است.

## قابلیت‌های نسخه ۳ (Features in Iteration 3)

### ۱. تقویم ماهانه خورشیدی و میلادی (Calendar Page)
- فعال‌سازی کامل ناوبری «تقویم و برنامه‌ریزی» در سایدبار دسکتاپ و تب موبایل.
- شبکه ماهانه تقویم خورشیدی (جلالی) با برچسب‌های فارسی و شروع هفته از **شنبه**.
- دکمه‌های ناوبری ماه قبل/بعد و دکمه بازگشت به «امروز».
- قابلیت سوییچ آزادانه بین تقویم **خورشیدی** و **میلادی (Gregorian)** بدون هیچ‌گونه دستکاری در تاریخ انتخابی یا تاریخ اقلام.
- استفاده از کتابخانه استاندارد `jalaali-js` برای احتساب دقیق سال‌های کبیسه، مرز اسفند/نوروز و طول ماه‌ها.
- نمایش نشانگرهای رنگی مجزا روی خانه‌های تقویم:
  - نقطه بنفش: تسک یا یادداشت برای روز انجام (`plannedDate`).
  - نقطه کهربایی: مهلت تحویل تسک (`dueDate`).

### ۲. برنامه روز انتخاب‌شده (Selected-Day Agenda)
- با کلیک روی هر روز، برنامه کاری آن روز در پنل کناری (دسکتاپ) یا زیر تقویم (موبایل) نمایش داده می‌شود.
- در صورتی که تسکی هم در این روز برای انجام برنامه‌ریزی شده و هم مهلت تحویل آن در همین روز باشد، تسک یک‌بار نمایش داده شده و هر دو عنوان به وضوح بر روی آن قید می‌گردند.
- امکان ثبت سریع تسک یا یادداشت به طور مستقیم برای همان روز انتخاب‌شده با ذکر تاریخ.
- دسترسی مستقیم به پنجره ویرایش تسک/یادداشت از طریق کارت‌های آجندا.

### ۳. معناشناسی دوگانه تاریخ‌ها (Date Semantics)
- تفکیک قطعی دو فیلد تاریخی:
  - `plannedDate`: «روز انجام» (تسک‌ها و یادداشت‌ها).
  - `dueDate`: «مهلت تحویل» (فقط برای تسک‌ها؛ یادداشت‌ها مهلت تحویل یا وضعیت عقب‌افتاده ندارند).
- تاریخ‌های ذخیره‌شده به عنوان تاریخ تقویمی (Calendar Date) در فرمت استاندارد `YYYY-MM-DD` نگهداری می‌شوند (بدون برچسب ساعت UTC-midnight).
- زمان ایجاد تسک (`createdAt`) دست‌نخورده باقی مانده و تبدیل به تاریخ برنامه‌ریزی نمی‌شود.

### ۴. منطقه زمانی تهران (Asia/Tehran) و غلتک روزانه (Day Rollover)
- تشخیص روز جاری بر اساس منطقه زمانی `Asia/Tehran` بدون نیاز به آفست دستی.
- به‌روزرسانی خودکار روز جاری هنگام فوکوس مجدد روی پنجره مرورگر (`focus`) و سنجش دوره‌ای غلتک روزانه.
- انتقال روزها بدون جابجا کردن خودکار یا تغییر اجباری تاریخ‌های کارهای دیروز.

### ۵. بخش‌های هوشمند صفحه امروز (Date-Aware Today Sections)
- **مهلت‌های گذشته (Overdue Deadlines)**: بخش تفکیک‌شده و هشداردهنده برای تسک‌های ناقصی که مهلت تحویل آن‌ها گذشته است (`dueDate < today`).
- **برنامه‌های انجام‌نشده قبلی (Overdue Planned Tasks)**: بخش تاشو برای تسک‌های ناقصی که تاریخ انجام آن‌ها قبلاً تعیین شده بوده است (`plannedDate < today`).
  - دکمه سریع و صریح **«انتقال به امروز»** جهت تغییر `plannedDate` به امروز بدون دستکاری مهلت، وضعیت، پروژه یا متن تسک.
- **برنامه‌های امروز (Main Today List)**: اقلام برنامه‌ریزی‌شده برای امروز به اضافه تسک‌های ناقصی که مهلت تحویلشان امروز است (تکثیر نشدن تسک‌های مشترک).
- **شمارشگر دقیق**: تعداد موارد باز بر اساس شناسه منحصربه‌فرد تسک‌ها محاسبه می‌شود و حضور یک تسک در بیش از یک بخش باعث افزایش کاذب تعداد نمی‌شود.
- تسک‌های انجام‌شده (`done` / `completed`) هرگز در وضعیت عقب‌افتاده قرار نمی‌گیرند.

### ۶. ادیتور اقلام و انتخاب‌گر تاریخ (Item Details & Date Controls)
- گزینه‌های سریع «امروز»، «فردا»، «انتخاب تاریخ» و «حذف تاریخ» برای روز انجام و مهلت تحویل.
- مدال تقویم تعاملی انتخاب تاریخ با پشتیبانی از هر دو تقویم شمسی و میلادی.
- نمایش هشدار در صورت تعیین روز انجام بعد از مهلت تحویل (`plannedDate > dueDate`).
- سوییچ «برنامه‌ریزی برای امروز» با اتصال مستقیم به تاریخ روز جاری تهران.

### ۷. مهاجرت امن و پشتیبان‌گیری نسخه ۳ (Safe Migration & Backup Compatibility)
- ارتقای نگارش اسکیمای محلی به **نسخه ۳**.
- تهیه اسنپ‌شات امنیتی پشتیبان پیش از مهاجرت (`karrooz_snapshot_pre_v3`).
- اقلام قدیمی دارای پرچم `inToday` در لحظه مهاجرت برای یک‌بار تاریخ روز جاری تهران را دریافت می‌کنند. مهاجرت کاملاً تکرارپذیر (Idempotent) بوده و با رفرش صفحه تاریخ‌ها جلو کشیده نمی‌شوند.
- پشتیبان‌گیری و بازیابی با فرمت JSON نگارش ۳:
  - پشتیبانی و اعتبارسنجی نگارش‌های ۱، ۲ و ۳.
  - پیش‌نمایش اقلام قدیمی فاقد تاریخ صریح و ارائه حق انتخاب به کاربر پیش از جایگزینی (تنظیم روی امروز یا بدون تاریخ).

## آزمون‌ها و بررسی‌های انجام‌شده (Verified Checks)

- **صحت محاسبات تقویم شمسی (Calendar Math)**:
  - اجرای موفق آزمون مرز سال کبیسه (اسفند ۱۴۰۳ برابر ۳۰ روز و اسفند ۱۴۰۲ برابر ۲۹ روز).
  - تبدیل دوطرفه نوروز ۱۴۰۳ به ۲۰۲۴-۰۳-۲۰ و بازگشت دقیق به ۱۴۰۳/۰۱/۰۱.
  - صحت تقسیم‌بندی روزهای شبکه تقویم بر عدد ۷ (با شروع از شنبه).
- **بررسی لایه تایپ و بیلد**:
  - اجرای موفق `tsc --noEmit` با خروجی کاملاً پاک و بدون خطا.
  - اجرای موفق بیلد پروداکشن با `vite build`.
- **بررسی چیدمان واکنش‌گرا**:
  - **موبایل (390px)**: تقویم فشرده در بالا، آجندای روز در پایین، تب جدید تقویم در نوار ناوبری پایین صفحه.
  - **دسکتاپ (1440px)**: چیدمان شبکه‌ای ۱۲ ستونی (۷ ستون تقویم ماه، ۵ ستون آجندای روز)، سایدبار کامل راست‌چین.

## محدودیت‌های فعلی (Current Limitations)

- سیستم کارهای تکرارشونده (Recurring Tasks) در این نسخه پیاده‌سازی نشده است.
- یادآورهای آنلاین یا نوتیفیکیشن‌های تحت وب در این فاز قرار ندارند.
- همگام‌سازی ابری و اتصال به تقویم‌های خارجی (Google Calendar و ...) در این فاز غیرفعال است و کلیه اطلاعات روی مرورگر همین دستگاه ذخیره می‌شود.
